A single razor-sharp line that excuses you from a pointless work meeting or
Zoom call — an entry for the make.fun bounty
[u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163](https://make.fun/competitions/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163).
The judge pairs excuses head to head and keeps the sharper, more relatable
laugh, so this entry goes for the biggest knowing laugh, not a mild smile.

## The entry

> Sorry, I have to skip — I read the agenda and my will to live filed a formal complaint with HR.

95 characters, one line. The joke escalates in three beats: a polite opener,
the surprising turn ("my will to live"), and the bureaucratic punchline
("filed a formal complaint with HR"). No wifi, no cat, no dentist — a fresh
angle that is instantly true to office life. See [CANDIDATES.md](CANDIDATES.md)
for the 10 candidates brainstormed and why this one was picked.

## Run it

```sh
python3 main.py
```

Prints exactly the entry line to stdout and writes the same bytes to
`/output/entry.txt`, where the grader reads it. Standard library only,
deterministic — the same bytes every run, with no trailing newline.
